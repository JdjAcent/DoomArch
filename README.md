# DoomArch

DoomArch is my personal Arch Linux + Hyprland environment.

The project is built incrementally with the goal of being understandable,
maintainable, portable, and reproducible across future hardware.

DoomArch is currently under active development. It is not yet intended to be a
plug-and-play configuration or complete installation for other systems.

KDE Plasma remains a temporary fallback environment while DoomArch becomes
independent enough to replace it.

This repository documents intentional decisions and configurations rather than
mirroring the entire system or `$HOME`.
