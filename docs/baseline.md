# Reference System Baseline

This document describes the machine currently used to develop DoomArch.
It is a reference environment, not a list of DoomArch requirements.

## Hardware

- Lenovo IdeaPad 3 14IML05
- Intel Core i5-10210U (4 cores / 8 threads)
- Intel UHD Graphics (Comet Lake-U GT2)
- 8 GiB RAM
- Internal display: 1920x1080 @ 60 Hz
- External display: Lenovo L24i-4A, 1920x1080 @ ~100 Hz

## System

- Arch Linux x86_64
- Linux Zen is currently the active kernel
- Linux and Linux Zen are both installed
- Intel i915 graphics driver
- Mesa graphics stack
- ext4 root filesystem
- 8 GiB swapfile
- Windows dual boot

## Desktop

- SDDM display manager
- KDE Plasma Wayland as stable fallback
- Hyprland Wayland as the DoomArch development environment
- Hyprland currently uses its autogenerated configuration

## Shared Infrastructure

- PipeWire + WirePlumber
- NetworkManager
- BlueZ
- polkit
- UPower
- UDisks2
